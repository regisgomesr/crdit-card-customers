# 📊 Credit Card Customer Churn Analysis

## 🎯 Sobre o projeto

Projeto de **Análise de Dados e Customer Churn** desenvolvido em Python e Google Colab com o objetivo de identificar os principais fatores associados ao **cancelamento de cartões de crédito** e encontrar padrões que possam ajudar uma instituição financeira a antecipar clientes com maior propensão ao churn.

O projeto simula um problema real de negócio: uma empresa de cartões está enfrentando um aumento significativo no número de clientes que cancelam seus cartões, gerando impactos financeiros e aumentando os custos de aquisição e retenção de clientes.

A partir de uma base histórica contendo informações de clientes ativos e clientes que cancelaram seus cartões, o objetivo é **explorar os dados, identificar padrões de comportamento e transformar os resultados da análise em insights para apoiar estratégias de retenção**.

---

## 💼 Problema de negócio

A empresa precisa responder perguntas como:

* Quais características estão mais associadas ao cancelamento?
* Quais perfis de clientes apresentam maior concentração de churn?
* Existem padrões relacionados a idade, renda, relacionamento com a empresa ou utilização do cartão?
* Quais comportamentos podem indicar risco de cancelamento?
* Como os dados podem apoiar ações preventivas de retenção?
* Quais clientes deveriam receber maior atenção antes de cancelar o cartão?

---

## 🔎 Etapas da análise

### 1. Importação dos dados

* Carregamento da base de clientes.
* Utilização do Pandas para leitura e manipulação dos dados.

### 2. Exploração e tratamento dos dados

* Verificação da estrutura da base.
* Análise dos tipos de dados.
* Identificação de valores ausentes.
* Verificação de inconsistências.
* Tratamento e preparação dos dados para análise.

### 3. Análise exploratória de dados — EDA

Investigação das principais características dos clientes e comparação entre clientes que permaneceram e clientes que cancelaram o cartão.

Foram analisadas variáveis relacionadas a:

* Perfil demográfico;
* Relacionamento com a instituição;
* Renda;
* Utilização do cartão;
* Número de produtos;
* Limite de crédito;
* Histórico de relacionamento;
* Frequência de utilização;
* Categorias relacionadas ao comportamento do cliente.

### 4. Identificação dos fatores associados ao churn

Comparação entre clientes ativos e clientes que cancelaram o cartão para identificar padrões e possíveis fatores associados ao cancelamento.

A análise busca transformar dados históricos em **insights acionáveis para o negócio**.

### 5. Insights e recomendações

Os resultados são utilizados para identificar segmentos com maior concentração de cancelamentos e levantar hipóteses para estratégias de retenção, como:

* Monitoramento de clientes com comportamento de risco;
* Criação de campanhas de retenção;
* Personalização de ofertas;
* Priorização de clientes para ações preventivas;
* Acompanhamento de indicadores de churn.
